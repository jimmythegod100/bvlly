# BVLLY diverse model options pack

Optional casting set for apparel mockups — **not** live lookbook replacements. All chests / fronts are blank (no logos, embroidery, or prints) so marks can be restamped later. Colorways align with `images/blank-garments/`.

**Total:** 36 images  
**Style:** Realistic streetwear photography · ages ~20–35 · varied body types  
**Naming:** `{garment}-{color}_{gender}-{ethnicity}.jpg`

| Token | Meaning |
|-------|---------|
| `f` / `m` / `nb` | woman / man / androgynous or non-binary-presenting |
| `black` | Black / African diaspora |
| `white` | White / European |
| `asian` | East Asian |
| `south-asian` | South Asian |
| `latina` / `latino` | Latino / Hispanic |
| `mena` | Middle Eastern / North African |
| `mixed` | Mixed heritage |

Garment keys: `mark-tee`, `beware-tee`, `beware-hood`, `mark-hood` (Mark Zip Set), `mark-shorts`, `mark-cap`, `bb-sweatsuit`.
