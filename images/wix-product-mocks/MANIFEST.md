## Wix upload tips

1. For each product colorway, set **Media → main image** to the primary `{sku}-{color}.jpg`.
2. Add the matching `-flat.jpg` (and BB detail views) as additional gallery images.
3. Prefer lookbook as the shop grid card if the brand wants on-body vibe; use `-flat` if Wix cards look too busy cropped.
4. Do **not** upload army green / beige / electric blue lookbook leftovers as purchasable variants — pink & black drop only (plus graphite shorts).
