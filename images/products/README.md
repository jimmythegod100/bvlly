# Catalog photos

On-body lookbook shots. Shop cards, product pages, and the hero use these — never empty-garment studio mocks as the preview.

Four colorways per piece: **beige**, **electric blue**, **black**, **army green**.

| File pattern | Piece |
|--------------|--------|
| `images/lookbook/beware-hood-{color}.jpg` | Beware Hood, worn |
| `images/lookbook/beware-tee-{color}.jpg` | Beware Tee, worn |
| `images/lookbook/mark-tee-{color}.jpg` | Mark Tee, worn |
| `images/lookbook/mark-hood-{color}.jpg` | Mark Hood, worn |
| `images/lookbook/mark-cap-{color}.jpg` | Mark Cap, worn |

`images/products/` still holds the original flats and embroidery close-up for print reference. They are not used as catalog previews.
