# Modesto brokerage shortlist

A planner for a newly licensed **California salesperson in Modesto** who wants to work independently — no floor time, no office culture.

It ranks cloud / 100% shops that can hang your license, compares year-one cost at a typical Central Valley commission, and tracks where you are in each application. Status is stored in your browser only.

## Who this is for

- New CA salesperson license
- Based in Modesto / Stanislaus County
- MLS: MetroList
- Local board: Lodi Association of REALTORS® (Modesto office, 421 E Morris Ave)

## Start here

1. Call **REeBroker Group** (DRE 01522411) — $0 monthly, no office, accepts new and dual-career agents.
2. Compare with **Real Estate Source** if you want a simple $595/file plan.
3. Use **Real** (no monthly) or **eXp** (most virtual training, $85/mo) only if you want a national platform.
4. Join LAR + MetroList after the brokerage certifies your DRE affiliation.

Skip Keller Williams, PMZ, Coldwell, Century 21, and Compass unless you decide you want an office.

Fees were researched August 2026. Get the independent contractor agreement in writing before you transfer on [DRE eLicensing](https://secure.dre.ca.gov/elicensing/).

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:43187](http://localhost:43187) if you start it with `npx next dev --port 43187`, or the port printed in the terminal.
